Frequently asked questions

How does remote computer support work?

After arranging an appointment, you'll receive instructions for joining a secure remote support session. Never share passwords or payment card details with a support agent.

Can every issue be fixed remotely?

No. Hardware faults, some network outages and certain security incidents may require in-person attention or specialist repair. We will explain the limitations before proceeding.

How long does an appointment take?

Remote Computer Help is planned as a 30-minute service. PC Speed-Up and Windows Security Check are planned as 60-minute services.

When can I book?

Planned availability is Monday–Friday, 09:00–14:00 and 18:00–20:00, UK time. Online booking is not yet active on this development site.

How will I pay?

Secure upfront payment will be available when booking and checkout integrations are completed. This development site does not collect card details.

What if I need to cancel?

The cancellation process and any statutory rights will be explained before checkout when bookings go live. Please use the existing Bytova website for current terms.
