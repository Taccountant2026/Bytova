Frequently asked questions

How does remote computer support work?

After arranging an appointment, you'll receive instructions for joining a secure remote support session. Never share passwords or payment card details with a support agent.

Can every issue be fixed remotely?

No. Hardware faults, some network outages and certain security incidents may require in-person attention or specialist repair. We will explain the limitations before proceeding.

How long does an appointment take?

Remote Computer Help is a 30-minute service. PC Speed-Up and Windows Security Check are 60-minute services.

When can I book?

Availability is Monday–Friday, 09:00–14:00 and 18:00–20:00, UK time. Select a service to book through Calendly.

How will I pay?

Fixed-price appointments use Calendly for booking and Stripe for secure payment. This website does not collect card details.

What if I need to cancel?

Review the cancellation conditions during booking and the current Bytova terms. Statutory consumer rights still apply.

Remote-first support: Bytova primarily provides remote support. Where an on-site call-out is necessary and available, this is a separate service, quoted and charged separately before any visit is agreed.
