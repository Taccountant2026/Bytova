Scanned Document Checks

Check that text and figures copied from scanned pages match the original documents.

All Services / Scanned Document Checks

Is this what you need?

You have a spreadsheet or text export from scanned forms, delivery notes or stock sheets and want it checked against the pages.

You receive a corrected copy, with unclear entries flagged by source page and field so you can resolve them.

What we can work on

  • Agree which fields to compare, such as item codes, dates or quantities.
  • Check the extracted values against the supplied scans.
  • Correct legible mismatches and flag unreadable characters or missing fields.
  • Return the checked file with references back to the original pages.

Useful details to bring

  • Describe the page count, layout and fields to check.
  • Provide a redacted sample scan and its matching extracted rows for the quote.
  • Choose the file format for the corrected copy.

Agreed before we begin

We agree the source pages and fields before work starts. Illegible values are marked for your review. The check confirms what the page says.

Work is undertaken only after suitability, scope and price are accepted. Your statutory rights are unaffected.
