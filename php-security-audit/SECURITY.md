# Security policy

This is an educational defensive utility. It is not an emergency response service.

Report a problem in this utility privately to **hello@bytova.co.uk** with the subject `PHP audit utility security report`. Include the release/dataset identifier, a minimal description, the classification you expected and a safe reproduction using synthetic version strings. Do not include secrets, customer records, exploit payloads, production logs or authentication credentials. Agree a secure transfer method separately if sensitive evidence is necessary. No response-time or bounty commitment is made.

Do not open a public issue containing sensitive vulnerability details. Coordinate disclosure and a corrective release privately. Vulnerabilities in PHP itself belong with [PHP's security process](https://www.php.net/security/), rather than a public issue in this tool. Do not scan or test systems without their owner's authorisation.

The current 1.x code is the maintained series for this draft release. Advisory data expires independently: `review_due` in the dataset controls positive safety comparisons. Use the newest reviewed dataset and read the limitations even when tests pass.
