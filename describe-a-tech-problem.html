A BETTER FIRST MESSAGE

Describe a tech problem clearly

You do not need technical language. A few useful details make the next step easier.

Help & Community / Describe a tech problem clearly

By Leighton at Bytova · Updated 19 October 2026

In this guide

  1. Start with what you wanted to do
  2. Name the device and the message
  3. Say when it started
  4. Share only what is needed
  5. Ask for a suitable next step

Start with what you wanted to do

For example: “I want to print a document from my laptop.” Then explain what happens instead. “The printer is switched on, but the document stays in the queue” is more useful than “it is broken”.

Name the device and the message

Include the computer, app or printer model if you know it, the Windows version if available, and the exact error text. It is fine to say you do not know. Do not include account passwords, licence keys or recovery codes.

Say when it started

Does it happen every time or only sometimes? Did it begin after an update, new app, move or change of equipment? Describe what you have already tried and what happened, rather than repeating changes just to make the message longer.

Share only what is needed

If a screenshot helps, remove or cover names, account numbers, messages, addresses and other private information first. A typed error message is often enough. Never send full card details or security codes.

Ask for a suitable next step

Say what a useful outcome would look like and whether you can use the device and internet connection. Bytova can then help you choose one of the three appointments or explain when a different kind of support is needed.
