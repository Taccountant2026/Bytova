Before you install

  1. Identify the web runtime, hosting owner and installation source.
  2. Preserve evidence if compromise is suspected; ask a qualified responder for help.
  3. Verify backups and a restore route, then test compatibility in staging.
  4. Apply the appropriate official/vendor update and replace affected running workers.
  5. Recheck the runtime/package and validate the website’s important functions.

A request you can send to your hosting provider

Select and copy this text into your existing support channel. Add only the account information your host needs; never include passwords or private keys.

Hello,

Please confirm whether the PHP runtime serving my website is affected by CVE-2026-109618 or CVE-2026-109619, and whether the fixes for both are installed.

Please provide the PHP build/package revision, the vendor advisory that confirms the fix, and confirmation that all affected workers were replaced. If an update is still needed, please confirm the maintenance plan, backup/restore arrangements and how website functionality will be checked.

Thank you.

A version result has a limited meaning.

This resource covers CVE-2026-109618 and CVE-2026-109619. It cannot determine whether a website is secure or compromised. Check the running web PHP and your vendor’s package record.
