# Bytova PHP Security Response 2026 — release candidate

Prepared 22 October 2026. Owner: Lnineon Liam Hepworth, trading as Bytova.

The release adds nine static resource pages, a browser checker, ten-step remediation wizard, five printable PDFs, an incident JSON template, a standalone Python utility, a dated source dataset and an organic campaign. The live website remains at https://bytova.co.uk/ on its existing GitHub Pages route. No PHP server, new hosting service, paid dependency or advertising spend is introduced.

## Important review boundaries

- The dataset concerns two CVEs only and was checked on 22 October 2026. Review is due 29 October. Recheck before a delayed launch.
- The version checker defaults to unknown installation source. Selected exact vendor matches are accepted; other vendor packages require manual review. Newer unreviewed releases, pre-release builds and expired positive data are unverified.
- The utility and wizard do not determine compromise, deploy updates, authenticate, scan or prove general security.
- Optional update requests open a local email draft. They do not create a live subscription. Lnineon must confirm a request and manage consent/withdrawal personally before sending updates.
- Optional assistance asks for suitability first. Existing £25/£35/£29 appointments retain their original scope and exclude active incidents; no automatic server-security booking funnel was added.
- All new metrics use the retained GA4 ID only after consent. The private RRUK aggregate service is not configured for these new pages, so the new pages bypass it. Existing ordinary-page aggregation stays intact.
- A private or local preview is not public deployment. Public HTTP and search-engine indexing cannot be verified until an approved production release. Sitemap/canonical/robots preparation does not establish indexing.
