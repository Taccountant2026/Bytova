# Local Bytova assets

- `Bytova_Logo.png`: the owner's approved circular 2026 V2 logo supplied 10 November 2026 as Bytova_Logo_2026_V2.jpg, losslessly decoded to PNG; supersedes the earlier rectangular wordmark.
- `leighton-workspace.webp`: the existing Bytova founder/workspace photograph, retained for the same business website.
- `inter-regular.woff2`, `inter-medium.woff2`, `inter-bold.woff2`: existing locally hosted Inter font files retained for branding. Inter is licensed under the SIL Open Font License; see `INTER-LICENSE.txt`.

- `journey-household.webp`, `journey-business.webp` and `journey-employer.webp` are illustrative images commissioned for the three customer routes. They depict example tasks.
- `youtube-windows-shortcut.webp` is the thumbnail of Bytova’s own featured Windows shortcuts video, obtained from its YouTube oEmbed record.
- `credly/*.webp` are resized versions of the Cisco learning badges awarded to Leighton Hepworth. Each badge image is paired with its individual public Credly verification URL in `data/cisco-credentials.json`.

The website requests these files from its own host. No external image, font, product or store request is required.
