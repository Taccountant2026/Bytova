# Local Bytova assets

- `Bytova_Logo.png`: the owner's uploaded Bytova logo, re-encoded from its original AVIF bytes to a valid PNG without visual changes.
- `leighton-workspace.webp`: the existing Bytova founder/workspace photograph, retained for the same business website.
- `inter-regular.woff2`, `inter-medium.woff2`, `inter-bold.woff2`: existing locally hosted Inter font files retained for branding. Inter is licensed under the SIL Open Font License; see `INTER-LICENSE.txt`.

The website requests these files from its own host. No external image, font, product or store request is required.
